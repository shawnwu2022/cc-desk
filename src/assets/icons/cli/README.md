# CC Desk CLI recognition marks

These two neutral SVG marks were created specifically for CC Desk and are
self-owned project artwork distributed under the repository's MIT license.
No official Anthropic or OpenAI logo or third-party artwork was copied.

- `claude.svg`: a conversation terminal mark
- `codex.svg`: a hexagonal code-bracket mark

They identify the CLI in CC Desk, without suggesting endorsement by either
provider. Both use the same fixed, low-saturation neutral ink (`#667587`),
independent of session state. The component applies a GUI dark-theme-only
neutral brightness treatment so the marks retain at least 3:1 contrast on
supported row backgrounds and selected overlays. `CC` / `CX` are only
image-loading-error fallbacks.
