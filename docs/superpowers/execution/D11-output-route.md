- Original native document tests and the loader smoke remain enabled. This increment does not enable an incomplete product startup/terminal path.

## Implemented boundaries

OutputRoutes reserves a callback lease before invoking a Channel constructor. Duplicates/capacity reject without constructing or dropping a conflicting native callback. RAII returns the slot on constructor error/panic; authorization is checked before and after construction. The route never exposes or clones its raw Channel.

OutputRoute serializes each route's sends. Before external authorization/dispatch it removes the Channel from the shared slot; only a confirmed Ok restores it. Error or unwind therefore leaves the route closed. The pending Channel owner is declared before the lock guard, so unwind releases that guard before Channel destruction. Ordinary failure also drops the guard before destruction. Original panics propagate; transport errors are redacted and no call is retried. The callback lease stays reserved until the final route/reader owner is dropped.

The bridge's optional third argument serializes only a canonical u32 Channel descriptor into the dedicated header; payload bytes and old two-argument calls are unchanged. Local Node VM checks after frontend RED passed valid zero/max descriptors, exact Unicode bytes, invalid/throwing descriptors without dispatch and query compatibility. This is not a local Vitest or native WebView run.

The native factory is called on the application's Arc-owned DocumentBinding. It authenticates through the existing native predicate before parsing the descriptor or reserving a callback. The factory then binds JavaScriptChannelId to the injected Webview, only after it wins the document's callback lease. Its send guard captures a Weak<DocumentBinding> and only the validated proof header, not the whole request or arbitrary headers. Each send reuses the existing ResourceTable pointer witness, exact URL, document readiness and backend instance/epoch checks. This avoids a second divergent admission implementation and avoids making the guard a strong document/registry owner. The existing native predicate releases ResourceTable locks before registry access. Product lifecycle still must explicitly retain and retire the appropriate owners.

Production-coordinator tests compose real OutputRoute leases with start_routed. Successful replay does not re-read profiles, construct another route or spawn again. Root exit retains the lease until explicit retirement. Failed spawn releases the route but retains the failed request result, so replay cannot disturb a newly bound independent route.

The Windows native Channel test uses the production bridge and native admission/factory, actual transformCallback/channel_on transport, four ordered byte payloads, duplicate binding rejection without closing the original callback, a second native WebView carrying the main proof/descriptor, and a send after real native destruction. Parent and worker require all five ordered observations and no sticky failure; failures include the safe report to assist diagnosis. The fixture exercises native callback primitives, not the JavaScript Channel class's out-of-order buffering implementation. Its test-only acknowledgment is exact equality of received packets, not the future xterm parser ACK protocol. No Claude/Codex or product startup runs in this test.

All 14 active Rust cases (ten route/descriptor, one native parent, three edges) and four frontend cases are retained. Only the formatter changes actually reported by CI and richer safe test failure diagnostics accompany implementation. Final complete CI must be checked on the successor head before claiming GREEN; record its result in PR metadata without an untested documentation successor.

## Outstanding boundaries

Production endpoint registration/lifecycle ownership and the event pump remain unenabled. Tauri 2.10.3 uses an application-wide fetch queue for larger Channel messages; this increment's small-frame native test does not certify large-message queue ownership, cancellation, pending-data cleanup or backpressure. Those must be resolved/tested with D13/D14 before any product stream is enabled. A native Channel retains its WebView/manager; lifecycle retirement must break manager/resource ownership cycles. The weak admission guard does not remove that Tauri ownership requirement. No broad authentication, complete D11 or installed-product claim is justified here.
