## Scope

D21 closes the approved W6 OS/platform boundary for the tested Windows Server 2022 target:

- stacked pull requests must actually run the private bundled-ConPTY installer certification;
- native CLI Node scripts used by Windows tests have deterministic LF checkout semantics;
- the inherited observer reporter regression harness works under Git Bash without changing production reporter semantics;
- pinned private ConPTY files are verified before use;
- the packaged application loads the bundled runtime from its own installation directory;
- relocation remains supported;
- missing/corrupt private runtime components fail closed and do not silently fall back to a CWD/system runtime;
- process/run supervision retains explicit ownership and does not auto-restart or perform system-wide process killing.

This is target-scoped evidence. Hosted Windows Server 2022 does not certify every Windows build, every machine, or D20 real CLI behavior.
