## Contract

- public native-error projection uses a fixed allowlist;
- arbitrary `Error.message` values and secret-looking public codes collapse to a fixed fallback;
- native workbench/terminal surfaces use interpolation only and contain no `v-html` / `innerHTML` execution path;
- native frontend components do not log user payloads through `console.*` or `logMessage`;
- native commands remain behind the authenticated document bridge;
- product-boundary tests reject an executable bare Tauri `invoke(...)` fallback;
- backend sensitive Debug surfaces are redacted;
- raw serde/native errors are not formatted back to callers.

## Boundary

Safe diagnostics report stable codes, not arbitrary native text. This is a product security boundary, not cosmetic error formatting.
