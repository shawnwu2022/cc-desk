# D26 — Log, DOM, IPC and observer security boundaries

Branch: `feat/native-cli-resilience-security`

## Scope

D26 hardens host boundaries without taking ownership of CLI authentication, model traffic or native terminal semantics.

## Invariants

- Frontend-originated log strings are content-redacted at the Rust logging boundary. Logs retain only byte count and level; no body, argv, path, prompt, clipboard content or guessable digest is retained.
- Native Workbench components do not use executable HTML sinks or automatic external URL opening.
- Native `cli_*` calls stay behind the authenticated document bridge and never fall back to ambient Tauri `invoke`.
- Observer events are delivered only to the owning WebView.
- Observer binding is authenticated before body allocation; body size, concurrency and replay/event admission remain bounded.
- Native workbench errors surface safe error codes rather than arbitrary exception text.
