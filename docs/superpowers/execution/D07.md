## Interface rulings

Pre-flight: D06 supplies global workspace CAS and profile last-change revisions. Project changes increment only the workspace revision and leave profile last-change revisions intact. D08 must not confuse the two scopes.
Ruling: project operations share D06 storage rather than adding a competing project file. Profile and unknown extension sections survive writes. The now-typed registeredProjects field rejects malformed content without overwriting it.
Ruling: the D06 unknown-extension fixture is renamed to futureProjectExtensions; registeredProjects is no longer an unknown extension. This does not weaken the malformed-project schema tests or drop unknown-field preservation coverage.
Ruling: directory identity is resolved outside the workspace lock. Registration commits against that snapshot revision and retries only definitely-unwritten CAS conflicts (at most 16 attempts), fixing concurrent alias duplication without keeping filesystem lookup under the storage lock. Other errors, especially COMMIT_STATE_UNKNOWN, are never automatically replayed.
Ruling: legacy project alias/pin/hidden inheritance reads Desk projects.json/config.json only. No archivedSessions, credentials, native settings or arbitrary fields are copied to new records or public responses. Conflicting alias projections report a warning rather than selecting a guessed winner.
Ruling: project list responses are a current reread after a mutation; if that read fails, the caller gets COMMIT_STATE_UNKNOWN and must reread, not repeat the mutation blindly.
Ruling: record-level native session/tree identity migration stays with D22/W7. This PR exposes and persists independent registration but does not claim the old history-based project tree, startup Claude checks, or Codex launcher have been migrated. Those remain explicit integration acceptance work, not hidden completion.
