## Contract

D22 establishes the product state model used by both native CLIs:

- strict fail-closed Claude/Codex profile storage;
- independent selected profile per CLI;
- explicit workspace revision/CAS with no automatic conflict retry;
- stable native Tab identity containing CLI, project, profile revision, request, run, generation and launch action;
- exact run+generation launch-status adoption;
- unknown launch outcome cannot allocate a replacement run;
- explicit restart allocates a new request/run and increments generation;
- empty-workspace bootstrap can create `codexDefault` and legacy-compatible `legacyClaude`;
- Codex-only initialization does not depend on legacy Claude startup checks.
