# D27 — Fair backpressure, low-resource and multi-run fault stress

Branch: `feat/native-cli-resilience-security`

## Scope

D27 stresses the existing bounded terminal transport. It does not increase budgets or weaken per-run/output ordering to make tests pass.

## Invariants

- Application payload accounting never exceeds the configured global budget.
- Many runs eventually make progress under a deliberately tiny global budget when ACKs release credit.
- One failed/revoked output route releases its reservations and does not block a healthy peer.
- Run identity and bytes remain isolated under concurrent delivery.
- Stress tests use reduced deterministic budgets rather than claiming production RSS or real-model performance.
