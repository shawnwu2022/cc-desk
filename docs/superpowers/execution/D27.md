## Contract

- global payload-budget waiters make FIFO progress;
- route revocation releases budget and wakes blocked peer senders;
- repeated runs under a deliberately small application budget converge to zero outstanding credit;
- wrong-owner ACK cannot release another run's credit;
- dropped stream ownership releases credit for blocked peers;
- out-of-order frontend parser callbacks never ACK across an unparsed gap;
- one degraded frontend run cannot poison a peer transport;
- stress synchronization uses test-only waiter-count state instead of timing guesses.
