## Scope and pre-flight

- Dedicated stacked feature branch; no main/merge/release/tag/version/lockfile changes. No changes to user CLI configuration or existing running terminal routes.
- Files searches returned no indexed D11/task content in this turn. The complete W2 D11 card and v3 contracts were read from the existing mounted planning ZIP, not invented or replaced by public sources.
- D08 produces an immutable LaunchSnapshot and backend CallerIdentity. D09 consumes its exact request; D10 consumes one invocation and returns generic process handles. D11 must reuse those types, never create a competing profile/env authority.
- Ruling: first establish the production coordinator/registry and frontend replay policy. Actual Tauri document-lifetime binding and existing PTY migration remain open until proved; do not claim internal owner tests establish live WebView authorization or expose an unauthenticated new spawn command.
- Ruling: a per-backend registry owns the current window epoch and non-reusable run IDs. Lifecycle invalidation before the spawn linearization point cancels the reservation; invalidation after that point revokes controls but does not discard or silently kill a process already being started.
- Ruling: process exit and resource retirement are separate; an early exit callback may precede spawn completion and must not be overwritten by Running. Output drain is still D14/D15, not inferred from this registry.
- Ruling: tombstones retain only routing IDs, fixed result enums and a private process-keyed request fingerprint. Never evict a tombstone and silently replay; capacity exhaustion rejects new requests. No cross-backend exactly-once claim.
- The generic resource parameter is the actual coordinator storage boundary for owned process/stream handles; countable test resources are not a second coordinator implementation. No native agents or credentials are needed for core races.
