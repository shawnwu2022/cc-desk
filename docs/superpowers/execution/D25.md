# D25 — Mixed-version rollback and crash recovery

Branch: `feat/native-cli-resilience-security`

## Scope

D25 locks the existing workspace durability mechanisms into an integration contract. It does not migrate native CLI data or invent a second storage authority.

## Invariants

- Legacy Claude configuration remains a backend-only inheritance source for `legacyClaude`.
- Workspace `set/unset` state is authoritative and later legacy writeback cannot revive deleted values.
- Codex never consumes legacy Claude env or permission settings.
- Unknown fields in schema v1 survive both profile writes and registered-project writes.
- A replace-completed write that reports `COMMIT_STATE_UNKNOWN` is reconciled by rereading; the old CAS revision is not replayed.
- Profile and project writes share the same workspace revision/lock and concurrent operations preserve both domains.
- Literal legacy/host secret values are never copied into `cli-workspace.v1.json`.

Product tests live in `src-tauri/src/tests/native_cli_resilience.rs`. Existing D06 storage fault, multi-process locking, unknown-field and atomic-replace tests remain part of the retained regression base.
