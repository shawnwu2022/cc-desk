# D25 — mixed-version rollback and legacy writeback safety

## Status

Implemented and verified on PR #32 at final head:

`6bdec882b54e59b502fa42c6b13ca487fc27e2d8`

## Contract

- old-package writes to legacy `config.json` / `projects.json` cannot mutate `cli-workspace.v1.json`;
- explicit `unset` and `set(false)` cannot be revived by later legacy values;
- Codex never inherits legacy Claude env/secret values;
- new native workspace writes do not touch legacy files;
- unknown workspace extensions survive mixed-version legacy writes and later native writes;
- commit-state-unknown remains non-retryable and must be reconciled by reread rather than blind replay.

## Boundary

Compatibility protects existing users without making legacy files authoritative for the new native store.
