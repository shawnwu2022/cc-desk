## Contract

The native workbench provides the complete host-side launch entry:

- new session;
- native resume picker;
- explicit known session-ID resume;
- exact raw argv JSON `string[]`;
- Codex picker supports current-project/all scope;
- Claude does not impersonate Codex `--all` behavior;
- raw argv is preserved verbatim and never shell-split;
- one owned launch attempt per `requestId`;
- uncertain start outcome is recovered only by querying the original request;
- native xterm uses authenticated `cli_start`, `cli_get_launch_status`, `cli_resize`, `cli_stop`, native staged input and output ACK;
- no fallback to legacy `ptySpawn` / `ptyInput` / `ptyKill`;
- keyboard, IME and paste use the ordered native writer;
- input is disabled while launch state is unknown/non-writable;
- active native tabs adopt natural exit state and require explicit restart.
