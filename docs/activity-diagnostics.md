# 操作诊断

设置 → 关于 → 操作诊断。每次启动应用默认关闭。开启后只记录之后开始的已接入操作；停止立即废弃在途记录句柄，可预览停止前最后一轮已收集的记录。重新开启清空旧报告。没有后台文件、自动复制或上传。复制按钮只复制已显示的快照。

首段只覆盖会话目录层的归档、取消归档、改名与已有原生删除流程。操作关联号是每次操作的随机 128 位值，同一轮报告内可关联，非会话 ID，不作为授权。记录是固定枚举、相对毫秒与饱和丢弃计数；最新 256 条覆盖更旧记录。不读标题、会话内容、终端文本、错误原文、路径、CLI 参数或凭据。列表阶段 returned 只说明刷新调用返回，不保证目标仍有效或已投影。删除 acknowledged 只沿用现有精确收据语义，不证明所有后代已删除。

| 首段路径 | 实际观测边界 |
|---|---|
| 归档、取消归档和改名 | UnifiedSessions store 的适配器回执阶段、既有刷新返回或错误；无原生 CLI 确认 |
| 删除 | NativeSessionDeletes store 现有 preview、确认、取消和只读 inspect；不改变任何执行或确认门 |
| 暂不覆盖 | 原生后台与 provider 阶段、列表真实提交、独立刷新、会话启动/恢复运行、应用退出、远程连接/取消、历史读取、保存到文件 |

后续需在真实调用路径继续贯穿随机关联号；不改 mutation 业务请求和既有请求 ID 语义，不把诊断参数当权限。Codex 原生归档/unarchive 与 Claude Desk 管理标记是不同路径；没有原生动作时显式报告未调用，不能虚称 CLI 成功。实际启动诊断接入后，开启时已发生的启动需复现对应会话，不要求重启整个应用。

验收分层：定向单测检查隐私、默认关闭、开停代际、饱和、错误透明与预览复制。Rust IPC 和 provider 事件接入后再验同号跨层、关闭确认后的在途回调拒绝、原生支持/不支持、刷新被替代和写确认未知；最终用标准安装包和独立真实 CLI 核验，不能以 mock 覆盖代替。
