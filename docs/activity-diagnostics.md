# 操作诊断

设置 → 关于 → 操作诊断。每次启动应用默认关闭。开启后仅记录之后开始的已接入操作；停止时前端立即销毁采集状态，后台以应答为准。未收到停止应答时页面显示尚未确认，可重试停止，不能重开采集。重新开启清空旧报告；停止后仍可预览最后一轮已收集的报告。无后台文件、自动复制、网络请求或上传。复制按钮只复制已显示的快照。

前后端各自最多保存最新 256 条。诊断只记录固定阶段、结果类别、相对毫秒和饱和的环覆盖计数；后端争用可丢事件，未记录到的阶段不能解读为未发生。使用每次操作随机生成的 128 位操作号关联两个时钟域，不记录真实会话 ID。来源配置、操作确认、文档身份和业务请求不因诊断开启而改变。采集令牌仅留在本地文档 IPC，不进报告、持久化、CLI 参数或环境。报告不读标题、内容、终端文本、错误原文、路径、CLI 参数、密钥或原始会话 ID。

| 路径 | 当前观测边界 |
|---|---|
| Codex 归档/取消归档 | 目录发起、正式 IPC、原生 helper 或 unarchive child、原刷新所有者的投影结果。回读失败不重发写操作。 |
| Claude 归档/取消归档 | Desk 元数据路径，无原生 CLI 时记录 skipped。不把界面标记当原生归档。 |
| 改名 | 适配器、正式 Native IPC、已有 provider helper、目标目录投影。Legacy 不支持的入口不冒充已调用。 |
| 原生永久删除 | 预览、确认、取消、只读检查以及 Codex 实际 provider；单条与批量沿用现有确认/收据和刷新折叠。acknowledged 不证明所有后代已经删除；Claude 永久删除不新增能力。 |
| Claude 旧恢复区 | 现有 list、只读重新核查、恢复请求和目标目录投影。分别报告 sourceObserved、storedObserved、unknown 与冲突，不将原处可见宣称为此请求已移动文件。不新增移除入口。 |
| 历史故障重试 | 仅显式点击问题的「重试」：记录本次仍归属的读取已应用、部分、失败或过期，再同号记录目标列表投影；不采集后台读取、原错误或历史内容。 |
| 列表刷新 | 只记录上述操作的目标投影：applied、unchanged、stale 或 failed。其它 CLI 行变化不冒充目标结果。 |
| 原生会话启动 | 通过真实启动入口观察原始收据：running 仅指 Native 运行登记状态，不证明 CLI 已就绪、终端解析或远程可用；既有收据重放只返回原状态。 |
| 尚未接入 | 独立刷新、终端解析与启动后的就绪、退出、远程连接/取消、普通历史读取、另存为文件。 |

已发生的操作不能补录。需要重新观察启动回执时，只重启对应会话，不需要重启整个应用。

验收分层：前端验证同进程启停、迟到应答、超时、脱敏、饱和、错误透明、目标较新刷新及显式复制；Rust 单测验证文档绑定、代际和缓存边界；独立真实 WebView 上以正式只读 IPC 验证畸形、重复和重放头不改业务返回。该 IPC 验收不执行真实删除，不等于真实 CLI 业务和标准包的完整验收。显式历史故障重试的 230 项通过记录仅来自四个定向前端测试套件，不是整仓结果。最终合成提交的 Windows 普通安装包及其真实 CLI 验收是独立门：真实 GUI 改名、执行永久删除均未验证，不以合成回执、只读预检或旧安装包替代。
