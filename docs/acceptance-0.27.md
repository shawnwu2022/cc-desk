# 0.27 隔离发布验收准备

本文件是待执行矩阵，不是验收通过记录。当前没有由受保护 main 晋升、以真实发布密钥签名的 0.27 候选；此开发分支不发布、不推送，也不修改当前用户安装、设置或 CLI 数据。测试签名及合成 IPC 不能补齐真实签名验收。

## 运行环境与输入

使用可销毁的 Windows x64 虚拟机及独立本地账户，保存虚拟机检查点。仅更改该隔离账户的 per-user 安装，CLI 数据和会话全部由 fixture 创建；不要仅靠切换 `CODEX_HOME` 等环境变量就认定 NSIS/Desk 用户数据已隔离。确认没有用户真实工作目录、令牌或应用进程进入虚拟机。

待提供：已发布且三平台签名验证通过的 0.27 RC；准确官方 Release、tag/source SHA、asset ID/size/hash/签名和 updater 清单；上一正式版的已审核 Windows x64 安装包；发布链 exact-main CI/coverage 证据。不得为了执行矩阵自行改 Release、线上清单或申请签名秘密。

## 待执行矩阵

| 场景 | 隔离操作 | 必须观察的结果 |
| --- | --- | --- |
| stable → RC → stable | 正式版默认 stable；显式选 test/preview；升级到真实签名 RC；使用已审核历史包和隔离数据恢复上一 stable | stable 从不收到 RC；旧客户端 latest 仍稳定；切回 stable 不自动降级；手动恢复范围/备份/兼容性明确。 |
| 通道与候选变动 | 检查后切通道、延迟旧检查回执、改变发布资产元数据 | 旧候选与 admission 失效，不能安装；排除 candidate/test-only、不可发布资产。 |
| 下载失败 | 隔离代理断网、取消、截断包、坏摘要、错误签名、超过大小上限 | 固定失败阶段，原安装保留；取消不会转为安装；仅显式重新检查后重试。 |
| 安装与重启 | 活动合成会话；取消安装器；模拟安装失败；检查恢复材料 | 活动时明确提示；不静默关会话或重启；未知结果不写成成功；保留既有可恢复点。 |
| 诊断 | 每种 CLI 两个合成 profile，版本成功/不可用/多行/超时；采集中切配置/关闭页面 | 只运行固定版本参数；来源不混淆；不复制 ID、路径、认证或正文；取消待收口，未知 owner 不重放。 |
| 永久删除窄能力 | 仅可销毁数据：Windows、已原生归档 Codex 根、同 ID 不同来源、活动/恢复/未知对象、外部 writer、变化后重预览、取消/丢回执/部分失败 | 预览与取消零 mutation；独立二次确认后一次 thread/delete；原生根及动态子树风险、关联维护与未核验数据明确；Job 后代收口前不释放来源；unknown先只读核查不重放。已有合成IPC/子进程验证，真实 Codex CLI/WebView 仍待单独授权的隔离验收；OpenCode/Claude 当前执行禁用。 |
| 会话回归 | 合成新建、首事件延迟、刷新、关闭、恢复、重命名、身份关联 | 三 CLI 每一项单独记录环境/版本/结果；不靠版本白名单跳过功能。 |

真实 macOS/Linux 安装、Windows 安装版 WebView、三 CLI D20、用户双行现场身份关联及 AI 自动命名另立记录。当前均未因源码和合成测试通过而自动验收。
